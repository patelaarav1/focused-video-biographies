# Focused Video Biographies

Documentaries about one life at a time. Live at GitHub Pages.

## Adding a documentary

Edit `videos.json` on GitHub (pencil icon) and add an entry:

```json
{
  "url": "https://www.youtube.com/watch?v=VIDEO_ID",
  "title": "Documentary title",
  "subject": "Who it's about",
  "note": "Optional note"
}
```

Separate entries with commas. Commit, and the site updates within a minute or two.
Entries whose link isn't a valid YouTube video are skipped.
